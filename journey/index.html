01 / Tech support

Helping merchants get more from their themes.

I started at Eight helping merchants set up and use their Shopify themes. I talked through what they wanted their storefronts to do, showed them which settings could get them there, and helped with small customisation requests. When the theme couldn’t do something out of the box, I explained the options and gave them a clear next step.

02 / Technical escalations

Resolving complex theme issues.

In escalations at Eight, I investigated Add to cart failures on older jQuery themes. I reproduced the issue and blocked third-party scripts one at a time in DevTools. When an app was responsible, I pointed the merchant to its developer. If ruling out apps didn’t solve it, I tested a clean copy of the theme on the same store to see where to look next.

Trello · Liquid · Notion · GitHub

Handoff paths

Get the fix to the right person.

App conflict
Send the merchant to the app developer once the conflicting script is identified.
Custom code
If the clean theme works, use Diffchecker to isolate what changed and share the findings with the developer.
Theme bug
If the clean theme also fails, trace the bug, fix it on a duplicate of the merchant’s theme, document the fix in Notion, and file a GitHub issue.

05 / AI-assisted development

Making AI part of the development workflow.

I used Claude Code to rebuild theme sections, develop features and debug issues. I took feedback from older tickets and turned it into focused acceptance criteria and browser checks with Claude in Chrome. I saved recurring pitfalls in a knowledge base so the agent could check for them next time.
