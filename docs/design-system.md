# Bernardine Richards portfolio concept

The audience is hiring teams exploring Shopify work. Real storefront previews supply the colour. The page reads like a small catalogue with room to inspect an individual piece.

## Signature

Use an image with an attached ruled caption. The image shows the work and the caption identifies its context. Carry this pairing through Sway, theme-family tiles and the experience gallery. The header and navigation stay quiet.

## Layout and interaction

Use a seven-to-five image/detail split. Keep the storefront recognisable in wide screenshots. At phone widths, the hero introduces the work above the image, and the experience picker precedes the selected exhibit. Collection cards sit four across on desktop and two across on phones. A neutral rule separates object from caption. Charcoal text, paper background, stone dividers and muted gray labels carry the hierarchy. Use square corners, a 44 px primary action, underlined secondary links, and a visible keyboard focus ring. Only the skills marquee moves continuously, with pause and reduced-motion support.

## Experience gallery

Present the existing five career chapters in chronological order as a selectable lookbook. Each entry has a first-person account and a related work sample or explicitly labelled illustration. Use project previews for theme and app work. Show the observed mismatch, duplicate-theme handoff and layout review for the support and QA entries. Keep the controls and panel position stable between selections.
